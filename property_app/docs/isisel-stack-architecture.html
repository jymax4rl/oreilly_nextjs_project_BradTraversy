02 · Program flow

How a request moves

Typical path for marketplace and console traffic — from the browser through auth and domain logic into MongoDB, with optional side effects.

Browser / PWA Pages · fetch · RSC
Next.js Middleware · handlers
NextAuth JWT · roles
MongoDB KamaProperties

Canonical sequence

1

Edge / middleware — locale cookie; redirect unauthenticated users away from /ops, /host, gated listing paths.

2

Page or Route Handler — Server Component render or app/api/**/route.js JSON / webhook.

3

Session check — getServerSession + role / hostStatus / ban flags from JWT.

4

Connect DB — connectToDatabase() → Mongoose against Atlas KamaProperties.

5

Domain utils — bookings, availability, creators, documentation, payments adapters.

6

Side effects — Cloudinary, Resend, payment gateway, web push, Sentry capture.

Deploy

Vercel project kemika02 → www.isisel.com. Optional Docker image for self-host.

Observability

Sentry Next.js SDK on server, edge, and client. Example routes for verify.

Keep-warm

Cron hits /api/health/db daily so Atlas M0 does not pause on idle.

03 · Product flows

Three programs, one stack

Guest marketplace, host workspace, and ops console share models and APIs — chrome and auth gates differ.

Guest

/ · /properties
  1. Explore home map & search via GET /api/properties.
  2. Open listing /properties/[id] with Maps + media.
  3. Request stay POST /api/bookings/request (phone, manual pay).
  4. Confirm offline WhatsApp / host — emails & push optional.
  5. Save bookmarks on /saved-properties.
Gate: Google sign-in for booking identity; catalog may be beta-closed.

Host

/host/*
  1. Onboard /host/onboarding → pending until verified.
  2. Home rings arrivals, departures, in-stay, needs-you.
  3. Calendar drag/resize availability blocks.
  4. Listings create/edit; ops moderates publish.
  5. Creators partnership tools under /host/creators.
Gate: hostStatus === "verified" (except install / onboarding).

Ops

/ops/* · /documentation
  1. Login credentials provider at /ops/login.
  2. Moderate users, listings, reservations, transactions.
  3. Market creators, investors, acquisition copilot.
  4. Analytics PDF/CSV reports from ops analytics utils.
  5. Docs KB seeded Mongo articles on /documentation.
Gate: role admin / superadmin; docs optional email restrict.

Shell chrome: guest floating tab bar · host top nav · ops side rail + sticky mobile bottom nav. Shared database and domain modules keep the three programs aligned across deploys.

04 · Integrations

External services

Side-effect services sit beside the monolith. Domain code in utils/ owns adapters so Route Handlers stay thin.

Cloudinary

Listing and avatar media upload, transforms, and folder provisioning under utils/cloudinary.

Google Maps

Map pins on home/search and Places autocomplete for address entry via utils/googleMaps.js.

Resend

Transactional and marketing email from verified @isisel.com templates (bookings, moderation).

Payments

GeniusPay preferred for ops MoMo; Creem demoted. Guests today: WhatsApp + manual confirmation.

Sentry

Error and performance monitoring across Node, edge, and browser for the Next.js app.

Vercel

Production hosting, Analytics, Blob storage, and scheduled cron for Atlas keep-warm.

Source of truth

Ops docs KB: application-, database-, and api-architecture under /documentation.
