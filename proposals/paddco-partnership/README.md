# ISISEL × PADDCO Partnership Proposal

Professional PDF proposal for a strategic technology & distribution partnership in Zanzibar.

## Files

- `ISISEL_PADDCO_Strategic_Partnership_Proposal.pdf` — final deliverable
- `proposal.html` — source layout (WeasyPrint)
- `build_pdf.py` — regenerate the PDF

## Regenerate

```bash
python3 build_pdf.py
```

Requires WeasyPrint (`pip install weasyprint`).
